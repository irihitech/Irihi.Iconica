# AGENTS.md

Guidance for AI coding agents working in this repository. Humans contributing code
should read `README.md`; agents should read this file first.

## What this repository is

Irihi.Iconica is a family of Avalonia icon libraries. Every upstream icon set
(IconPark, TDesign, ...) ships as its own NuGet package, generated from a pinned
git submodule by a console generator. The recurring task in this repo is
**adding or refreshing an icon set** — follow
[`docs/adding-a-new-icon-set.md`](docs/adding-a-new-icon-set.md) when asked to do that.

## Repository map

| Path | Role |
|---|---|
| `src/Irihi.Iconica.Core` | Shared drawing model (`DrawingElement`, `DrawingContextExtensions`). Referenced by every icon package. |
| `src/Irihi.Iconica.<Set>` | One publishable package per upstream set. Hand-written `<Set>IconBase` control in `Core/`, machine-generated icon classes in `Generated/`. |
| `src/IconGenerator.<Set>` | Console app that parses the upstream submodule and regenerates `Generated/` plus demo metadata. |
| `external/<repo>` | Git submodules pinning upstream icon sources. Read-only inputs. |
| `demo/Irihi.Iconica.Demo` | Shared gallery UI (Views/ViewModels/Models). Hosted by `.Desktop` and `.Browser` projects. |
| `.github/workflows/` | CI. All publishing workflows are manually triggered (`workflow_dispatch`). |
| `Irihi.Iconica.slnx` | Solution. Keep in sync when projects are added. |

Per-set pattern (the "five pieces"): **submodule → generator → package → demo wiring → CI pack entry**.

## Hard rules

1. **Never hand-edit generated code.** Everything under `src/Irihi.Iconica.*/Generated/`
   and `demo/Irihi.Iconica.Demo/Models/IconInfo.*.Generated.cs` is machine-generated.
   Change the generator, then re-run it.
2. **`external/` submodules are read-only.** Never modify or commit changes inside
   them; move the submodule pin only when deliberately upgrading the upstream source.
3. **Generators must stay idempotent.** Running a generator twice with unchanged
   inputs must produce a zero diff (headers carry no dates). After touching any
   generator, verify: run it twice and compare `git diff` — it must be identical.
4. **Generators fail fast.** Per-icon parse failures are collected, printed to
   stderr with a summary, and the process exits with code 1. Never swallow errors.
5. **Central package versions only** — `Directory.Packages.props` (CPM).
6. The demo intentionally overrides `Avalonia` to 12.1.1 via `demo/Directory.Build.targets`
   while `src` packages use 12.0.1. Do not "fix" this mismatch.

## Commands

```bash
# One-time setup after clone
git submodule update --init

# Build everything
dotnet build Irihi.Iconica.slnx

# Regenerate icons (requires initialized submodules).
# -f is required because generators multi-target net8.0/net10.0.
dotnet run --project src/IconGenerator.IconPark -f net10.0
dotnet run --project src/IconGenerator.TDesign  -f net10.0

# Optional: explicit repo root (works from any working directory)
dotnet run --project src/IconGenerator.TDesign -f net10.0 --root /absolute/path/to/Irihi.Iconica

# Run the demo (desktop)
dotnet run --project demo/Irihi.Iconica.Demo.Desktop

# Browser demo (requires 'dotnet workload install wasm-tools' once)
dotnet run --project demo/Irihi.Iconica.Demo.Browser

# Pack a package locally
dotnet pack src/Irihi.Iconica.TDesign -o nugets
```

## Generated file header

A single comment line, no dates, no copyright years (attribution and licensing
live in each package's `NOTICE`, which is packed into the NuGet package):

```csharp
// AutoGenerated by IRIHI Iconica <Set> IconGenerator
```

## Gotchas

- Regenerating IconPark rewrites ~2600 files; large diffs under `Generated/` are
  expected. Review by sampling, not file-by-file.
- Demo icon metadata lives in a hand-written partial class
  (`demo/Irihi.Iconica.Demo/Models/IconInfo.cs`) plus one generated partial per set.
- Package `RootNamespace` is `Irihi.Iconica` while assembly names differ; XAML
  xmlns mappings are declared in each package's `Properties/AssemblyInfo.cs`.
- Release flow: `release-tag.yml` (manual dispatch) → reuses `pack.yml` + `publish.yml`
  → creates a draft GitHub release with nupkgs and the demo zip.
- Do not commit the `.zcode/` directory or other local tooling artifacts.

## Conventions

- Code, comments, commit messages, and PRs in English. Conventional Commits
  (`feat:` / `fix:` / `chore:` / `ci:` ...), one logical change per commit.
- This is Avalonia, not WPF: `StyledProperty`/`DirectProperty`, `avares://`,
  ControlTheme/pseudo-classes, no `System.Windows.*` concepts.
- Icon controls render via `DrawingContext` using Core's `DrawingElement` model;
  appearance properties are StyledProperties on the `<Set>IconBase` class, not styles.
